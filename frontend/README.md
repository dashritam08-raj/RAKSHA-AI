# RAKSHA AI Frontend v4

## Local
```powershell
npm install
npm run dev
```

Set `VITE_API_URL` and `VITE_WS_URL` in `.env` for a deployed backend.

## Production
Build with:
```powershell
npm run build
```
Serve the generated `dist/` directory from a HTTPS-capable host. Browser GPS and WSS should be used in public deployment.
